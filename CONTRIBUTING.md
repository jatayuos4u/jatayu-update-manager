# Contributing

Thank you for helping improve Jatayu Update Manager.

1. Open an issue describing the problem or proposed change.
2. Make changes on a feature branch and submit a pull request.
3. Run `PYTHONPATH=src python3 -m unittest discover -s tests -v`.
4. Test privileged update flows only in a disposable Debian 13/JatayuOS VM.
5. Include English and Hindi translations for all new user-facing strings.

Please do not post passwords, tokens, private package repository credentials, or sensitive APT logs in issues.
